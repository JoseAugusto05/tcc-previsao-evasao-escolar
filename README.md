# TCC previsão evasão escolar

#🎓 Previsão de Evasão Escolar com Machine Learning
📌 Sobre o Projeto

Este projeto foi desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Tecnologia em Sistemas para Internet.

O objetivo é analisar e comparar diferentes algoritmos de Aprendizado de Máquina para prever a evasão escolar, identificando estudantes com maior risco de abandono antes da conclusão de seus estudos. A proposta busca demonstrar como técnicas de Ciência de Dados podem auxiliar instituições de ensino na tomada de decisões e na criação de estratégias preventivas.

🎯 Objetivos
Realizar análise exploratória de dados educacionais.
Identificar padrões relacionados à evasão escolar.
Treinar e comparar diferentes modelos de Machine Learning.
Avaliar o desempenho dos modelos utilizando métricas de classificação.
Identificar o algoritmo mais adequado para previsão de evasão escolar.
🛠 Tecnologias Utilizadas
Python
Pandas
NumPy
Scikit-Learn
Matplotlib
Seaborn
Google Colab
📊 Base de Dados

Foi utilizado um conjunto de dados educacionais público disponibilizado pelo repositório:

UC Irvine Machine Learning Repository

A base contém informações acadêmicas, demográficas e socioeconômicas utilizadas para treinamento e avaliação dos modelos.

🔎 Etapas do Projeto
1. Coleta e Pré-processamento
Carregamento dos dados
Tratamento de inconsistências
Preparação das variáveis para modelagem
2. Análise Exploratória dos Dados (EDA)

Foram produzidas análises como:

Distribuição dos alunos por status acadêmico
Distribuição por gênero
Matriz de Correlação de Pearson
Identificação de padrões relacionados à evasão escolar
3. Treinamento dos Modelos

Os seguintes algoritmos foram avaliados:

Decision Tree
Random Forest
Regressão Logística
Support Vector Machine (SVM)
Rede Neural Artificial (MLPClassifier)
4. Avaliação

Os modelos foram comparados utilizando:

Precisão (Precision)
Recall
F1-Score
Acurácia
🏆 Principais Resultados

O modelo Random Forest apresentou o melhor desempenho entre todos os algoritmos avaliados, alcançando:

F1-Score: 0,81
Melhor equilíbrio entre Precisão e Recall
Melhor capacidade de identificação de alunos em risco de evasão escolar

Os resultados demonstram o potencial do aprendizado de máquina como ferramenta de apoio para instituições de ensino na identificação precoce de estudantes com risco de abandono.
